# Original graphics handoff

Upload separate original PNG files here, not screenshots or thumbnails. Do not
bake live UI labels, navigation or controls into the artwork. Use real alpha
transparency where needed, not a painted checkerboard.

Update manifest.json only after the original file has actually been committed.
Record its filename, actual dimensions, transparency, byte size, SHA-256 and
intended use. Keep stable filenames and do not regenerate completed artwork
merely to populate this directory.

Never upload personal photographs, documents, saves, credentials or private logs.
Do not claim local implementation merely because a file exists in GitHub.
The receiving developer must validate the original and preserve live HTML,
accessibility, navigation and application behavior during integration.

The manifest currently contains one delivered library background. No other
original from the thirteen-item graphics series has been delivered here.
