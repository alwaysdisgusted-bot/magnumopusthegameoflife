# Contributor boundaries

- This is a public source-only repository for a local application.
- Never commit saves, documents, user photographs, databases, credentials,
  backups, runtime state or private workflow records.
- Keep personal mode bound to 127.0.0.1:4175 with MAGNUM_LOCAL_MODE=1.
- Preserve existing controls, documents, accessibility and storage boundaries.
- Original PNG handoffs belong in public/assets/magnum-opus/ with an accurate
  manifest. A generated preview is not proof of a delivered original.
- Do not enable graphics monitoring, scheduled generation, hosting deployment,
  paid services or automatic merging without an explicit user request.
- Use targeted checks. Do not automatically run the complete test suite.
- See SOURCE.md for setup and the scope of this source snapshot.
